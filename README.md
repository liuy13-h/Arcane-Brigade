# 奥术旅团 Arcane Brigade — 游戏规则设计

定位：**1–4 人在线合作的友伤弹幕天堂**。类幸存者玩法（默认自动开火，可切手动瞄准开火），
但所有系统都围绕"四个人一起乱"来设计。

规模控制：4 个职业、**主动技能 + 被动池（可重复叠层）**、4 种元素、4 只等级 Boss + 1 只剧情 Boss（奶蛙）。
槽位：**3 主动 + 无上限被动**——主动刻意少，深度全在被动的乘算上。

## 0. 快速开始：把项目跑起来

### 环境要求

- **JDK 17 或更高**（17 / 21 / 25 都行）。工程编译基线是 `--release 17`，
  生成的 class 版本为 61，任何装了 JDK 17+ 的机器都能直接跑。
- **不用单独安装 JavaFX**。依赖由 Maven 自动拉取（`org.openjfx:javafx-*:21.0.12`），
  并会**按构建所在系统自动选择 `win` / `mac` / `linux` 平台包**，同一份工程跨平台无需改配置。
- **首次导入需要联网**（Maven 要下载 JavaFX 依赖，约 30 MB）。

### 方式一：IntelliJ IDEA（推荐）

1. `File → Open`，选择克隆下来的**项目根目录**（即包含根 `pom.xml` 的那一层）。
2. 出现 Maven 导入提示时选择**导入 / 信任该项目**，等右下角依赖下载与索引完成（首次约 1–3 分钟）。
3. 确认 `File → Project Structure → Project SDK` 为 **17 或更高**。
4. 打开 `client/src/main/java/com/arcanebrigade/client/GameLauncher.java`，
   右键 **Run 'GameLauncher.main()'** 即可。

> **⚠️ 不要直接运行 `GameApp`**（或 `MapPreview` 等 `Application` 子类）。IDEA 会允许你点运行按钮，
> 但 Application 子类要求 JavaFX 在模块路径上，以 classpath 方式启动会被 JavaFX 拒绝并报
> **「缺少 JavaFX 运行时组件，需要使用该组件来运行此应用程序」**——这不是依赖缺失，是启动方式不对。
> 始终用 `GameLauncher`（或仓库内置的 `.run/启动游戏 (GameLauncher)` 运行配置）。

> Maven 面板跑法：`Arcane Brigade : Client` → 插件 → `javafx` → 双击 `javafx:run`
> （注意选 **Client** 子项目，根项目没有主类；见方式二）。

> 运行配置的 **Working directory** 保持默认即可。即便被设成了模块目录（`client/`）也没关系——
> 美术与音频资源是从工作目录**逐级向上**查找的，两种设置都找得到。

> 控制台若出现 `Unsupported JavaFX configuration`（unnamed module）属于**正常警告**，不影响运行：
> JavaFX 以 classpath 方式加载，启动类 `GameLauncher` 是独立于 `Application` 子类的，
> 正是为了绕开 "JavaFX runtime components are missing" 而这样设计。

### 方式二：命令行（Maven）

```bash
mvn install -DskipTests        # 首次：把 core 模块装进本地仓库
mvn -pl client javafx:run      # 启动游戏
```

> `javafx:run` **必须带 `-pl client`**。本工程是 `core` + `client` 的聚合工程，
> 父工程 `packaging=pom` 没有可运行的主类，直接在根目录执行会报 `mainClass missing`。

### 方式三：Windows 一键启动

双击项目根目录的 **`run.bat`**：它会用 `javac --release 17` 重新编译 core 与 client 后启动，
保证运行的字节码与当前源码一致（需要 `javac` 在 PATH 上，且 JavaFX 依赖已被 Maven 下载到本地仓库）。

### 排错

| 现象 | 原因与处理 |
|---|---|
| 报「缺少 JavaFX 运行时组件」 | 直接运行了 `GameApp` 等 `Application` 子类。改用 `GameLauncher` 或运行配置「启动游戏 (GameLauncher)」 |
| 提示缺少 `image/` 或 `audio/` | 这两个目录默认就在仓库里；若用了非标准工作目录，把 `Working directory` 改回项目根即可 |
| 没有背景音乐 | 缺音频文件或无声卡时游戏会**静默降级**，只是没 BGM，不影响运行 |
| Maven 报找不到 JavaFX 依赖 | 首次需要联网；或在 IDEA 里 Maven 面板点 **Reload All Maven Projects** |
| 想快速验证能否正常渲染 | 加 JVM 参数 `-Dab.smoke=120` 可自动跑 120 帧后退出；`-Dab.class=1..4` 指定职业，`-Dab.boss=0..3` 直接刷 Boss |

## 1. 核心循环

```
走位躲避 ──▶ 法术自动/手动开火 ──▶ 击杀掉经验宝石
   ▲                                    │
   │                                    ▼
   └──── 变强（构筑成型）◀── 升级三选一 ◀── 经验槽满
```

- **默认自动开火**；可按按钮切到**手动模式**——按住鼠标左键朝准星方向开火。
- **暂停**：按 **ESC** 或点击左上角「暂停」按钮随时暂停/继续（暂停时冻结模拟，仍显示画面）。
- 敌人从屏幕外的环形区域持续涌入，密度随时间上升。
- 击杀掉落经验宝石，靠近自动吸附；经验满 → 暂停 → 三选一 → 继续。
- 难度靠"敌人数量 × 强度"双轴爬升，玩家靠"法术数量 × 词条协同"跟上。
- **4 只等级 Boss（Lv.4 / 8 / 12 / 16）为中途精英**，击杀不再结束对局；
- **奶蛙（第 5 关 Boss）在玩家 Lv.25 时从场地中央刷新，击败奶蛙 = 通关**；角色血量归零 = 失败。
- **地图边界（棕色城墙）**：地图四周的棕色碎石城墙就是边界，玩家/敌人被挡在城墙内侧，
  贴到棕色墙体即停下（可玩区半宽 `PLAY_HALF = 1544`，城墙厚 56）。

## 2. 职业（法师 / 战士 / 弓箭手 / 召唤师）

四个职业共用同一套技能系统（独立冷却 + 强化路径 + 元素注入），
差别在**攻击形态、属性、专属技能池**。攻击形态的差异是根本——它决定了你怎么站位。

| 职业 | 攻击形态 | HP | 移速 | 特性 | 定位 |
|---|---|---|---|---|---|
| 法师 | 远程弹幕，自动索敌 | 200 | 200 | 每 30 秒一次免费重抽；法术伤害 +10% | 均衡，构筑最自由 |
| 战士 | 近战弧形挥砍（半径 90 / 扇形 120°） | 280 | 190 | 受伤减免 15%；每次击杀回 2 HP | 近身肉盾，靠站位吃饭 |
| 弓箭手 | 远程直线箭矢，天生穿透 1 | 160 | 230 | 暴击率 +10%；移速最快 | 玻璃大炮，风筝流 |
| 召唤师 | 远程秘能弹 + 宠物军团 | 180 | 180 | 每 10 秒召唤 4 只宠物护主；点鼠标下令集火 | 召唤控场，宠物承伤 |

初始攻击数值：

| 职业 | 伤害 | 冷却 | 备注 |
|---|---|---|---|
| 法师（魔弹） | 30 | 0.30s | 弹速 470，单体 |
| 战士（挥砍） | 52 | 0.55s | **命中扇形内所有敌人**，无需单体判定 |
| 弓箭手（箭矢） | 50 | 0.45s | 弹速 700，穿透 1 |
| 召唤师（秘能弹） | 20 | 0.42s | 弹速 500，单体，秘法元素 |

- 战士的近战形态意味着他必须往怪堆里扎，所以给了最高 HP 和减伤；
  弓箭手反过来，最脆但最快，靠拉开距离活命。
- **受击无敌帧按职业区分**：法师 0.35s / 召唤师 0.32s / 弓箭手 0.30s / 战士 0.12s。
- 每秒自然回血 0.6。

### 召唤师与宠物

- 每 `10` 秒召唤一批固定 `4` 只宠物，新一批到来时**先解散旧一批**（替换而非叠加）。
- 宠物血量 = **当前小怪血 × 2**，随小怪成长曲线同步上涨。
- 宠物**护主**：能吸引仇恨、挡住敌方弹幕；敌方索敌范围扩展为"玩家 + 宠物"。
- **听指挥 > 护主**：按住鼠标左键下令集火，宠物优先朝点击方向进攻，否则退回主人身边护主。
- **拴绳**：宠物只能在召唤师身边 `330` 范围内活动，越界立即拉回。

### 专属技能池

技能池按职业划分，四个职业各有一组专属主动。

| 职业 | 技能池 |
|---|---|
| 法师 | 魔弹、火球、冰锥、连锁闪电 |
| 战士 | 回旋斩、冲锋、裂地 |
| 弓箭手 | 多重箭、追踪箭、箭雨 |
| 召唤师 | 秘能弹、秘能球、灵体箭幕、秘法脉冲（全秘法元素） |

> 每职业只留 3–4 个主动。原计划里的旋风、毒云、战吼护盾、钉刺陷阱
> 全部改造成被动——它们本来就是"挂上去就生效"的效果，不该占主动槽。

**元素注入在四个职业上的表现不同，但反应规则通用**：
- 法师 → 法术附元素（火球、冰霜新星）
- 战士 → 武器附魔（火焰剑、冰霜锤）
- 弓箭手 → 箭矢附魔（火箭、雷箭）
- 召唤师 → 秘法专精（全部技能秘法元素）

**弹幕敌我区分**：玩家弹按元素上色，敌方弹统一"敌意红"，一眼分清哪颗要躲。

## 3. 技能与法术系统（游戏的灵魂）

槽位设计：**3 个主动 + 无上限被动**。

主动技能刻意压到 3 个——类幸存者里主动技能是自动释放的，堆多了玩家根本感知不到，
反而稀释构筑焦点。深度交给**无上限的被动**：被动之间互相乘算，才是"一局一个玩法"的来源。

四职业共用这套规则，区别只是各自能抽到哪个池子。

下表是**法师法术池**，从 6 个精简到 4 个，覆盖单体 / 范围 / 穿透 / 弹射四种形态。
原来的"旋风"和"毒云"改造成被动，不再占用主动槽。

| 法术 | 类型 | 基础数值 | 强化方向 |
|---|---|---|---|
| 魔弹 | 单体直线 | 30 伤害 / 0.30s CD / 速度 470 | 数量、穿透、暴击 |
| 火球 | 范围爆炸 | 44 伤害 / 1.1s CD / 爆炸半径 60 / 燃烧 12 每秒持续 3 秒 | 范围、燃烧时长、二次爆炸 |
| 冰锥 | 穿透直线 | 32 伤害 / 0.8s CD / 穿透 2 / 减速 35% 持续 2 秒 | 穿透数、减速强度、命中分裂 |
| 连锁闪电 | 弹射 | 24 伤害 / 0.9s CD / 弹射 3 次 / 每次衰减 15% | 弹射数、降低衰减、暴击 |

### 元素注入

每个法术可注入一种元素，改变其行为：

- **火焰**：附加燃烧 DoT
- **冰霜**：附加减速
- **雷电**：命中时向附近敌人跳一次小电弧
- **秘法**：+20% 伤害，无视减速抗性

> **元素技能解锁规则**：技能自带元素，抽卡时**必须有对应元素的附魔被动**才会出现——
> 火球/烈焰新星需【火焰亲和】、冰锥/绝对零度需【冰霜亲和】、连锁闪电/雷霆风暴需【雷电亲和】、
> 秘法系（魔弹、召唤师全套）需【秘法亲和】；无附魔与毒系技能不受此限。
> 该限制**只作用于三选一抽卡**，已获得的技能不会因缺被动而失效。

### 元素反应（协同的核心乐趣）

| 组合 | 效果 |
|---|---|
| 燃烧 + 冰霜 | **蒸汽爆发**：范围 80 内一次 40 伤害并致盲 1 秒 |
| 冰冻 + 雷电 | **超导**：破冰，额外 60% 伤害并眩晕 1 秒 |
| 燃烧 + 雷电 | **过载**：爆炸击退周围敌人 |
| 中毒 + 燃烧 | **引爆**：立即结算剩余全部毒伤 |

> 设计要点：反应必须是**可被玩家主动凑出来**的，UI 要在选词条时提示"与已有法术形成 XX 反应"。
> 这才是这类游戏让人上瘾的地方——不是数值变大，是玩法突然变了。

## 4. 被动系统（真正的构筑深度）

无上限被动。被动不是"加数字"，而是**互相乘算**——这才是重开一局的理由。

> 标注 **★可重复** 的被动（力量训练 / 精准 / 致命一击 / 疾速 / 巨化 / 延烧 / 强健 / 坚壁 / 再生 / 迅捷 / 贪婪 / 智慧）
> **不占用被动栏位，可反复选择叠加**（上限 99 层）。

- 击杀掉经验宝石，拾取半径 60（可被被动放大）。
- 升级时暂停并弹出三选一；稀有度权重：普通 60% / 稀有 30% / 史诗 10%。
- 三选一的选项构成：主动技能（**仅在未满 3 槽时出现**）+ 被动（主要来源）。

| 致命一击 ★可重复 | 暴击伤害 +80% | 稀有 |
| 疾速 ★可重复 | 攻击速度 +40% | 普通 |
| 穿透弹 | 所有投射物 +1 穿透 | 稀有 |

| 巨化 ★可重复 | 所有范围效果 +50% | 普通 |
| 延烧 ★可重复 | 持续伤害时长 +20% | 普通 |

**资源类（5）**

|---|---|---|

**质变类（4，是设计的核心）**

| 被动 | 效果 | 稀有度 |
|---|---|---|
| **孤注一掷** | 只装备 1 个主动技能时，其伤害 +150%、冷却 −50% | 史诗 |
| 连锁反应 | 元素反应范围 +50% | 史诗 |
| 临界质量 | 穿透 ≥ 5 时全伤害 +50% | 史诗 |
| 弹幕之王 | 投射物数量 ≥ 8 时攻速 +25% | 史诗 |

> **孤注一掷是这个设计的锚点**：它明确奖励"少带主动技能"的极端构筑，
> 让"3 个槽到底塞不塞满"变成一个真实抉择，而不是无脑填满。

### 由主动改造而来的被动

| 被动 | 前身 | 效果 |
|---|---|---|
| 环绕旋风 | 旋风 | 身边持续旋转伤害场：8 伤害 / 0.4 秒 / 半径 90 |
| 毒雾轨迹 | 毒云 | 移动时留下毒雾：5 伤害每 0.5 秒，持续 4 秒 |
| 战吼护盾 | 战吼护盾 | 每 25 秒自动获得 30 点护盾并击退周围敌人 |
| 钉刺陷阱 | 钉刺陷阱 | 每移动一段距离自动布下陷阱，触发造成 30 伤害并定身 1 秒 |

### 技能进化（主动 + 催化剂被动 → 质变）

集齐指定被动后，对应主动技能永久进化。给收集被动一个明确目标，避免"随便选选"：

| 主动技能 | 催化剂 | 进化后 |
|---|---|---|
| 魔弹 | 穿透弹 | **魔弹风暴**：齐射 5 发且必定穿透 |
| 火球 | 延烧 | **烈焰新星**：爆炸后留下持续燃烧区域 |
| 冰锥 | 冰霜亲和 | **绝对零度**：命中冻结 1 秒 |
| 连锁闪电 | 雷电亲和 | **雷霆风暴**：弹射不再衰减，且每次弹射范围 +30% |

### 质变阈值（"协同"的具象化）

某些强化堆到阈值会改变技能行为，而不只是加数字：

- 魔弹 数量 ≥ 5 → 变为扇形齐射
- 冰锥 穿透 ≥ 5 → 命中后分裂成 3 枚碎片
- 连锁闪电 弹射 ≥ 6 → 闪电在敌人之间形成持续电网

## 5. 敌人与波次

| 类型 | HP | 速度 | 伤害 | 行为 |
|---|---|---|---|---|
| 史莱姆 | 52 | 92 | 9 | 直线追踪，数量最多 |
| 蝙蝠 | 32 | 140 | 7 | 快而脆，斜向切入 |
| 兽人 | 140 | 70 | 16 | 厚血慢速，正面硬冲 |

## 6. 小队规则（本作的差异化）

### 友军伤害

- **友伤常开，不可关闭**。对队友造成 30% 伤害。
- 这是刻意的：它制造混乱、制造节目效果，也逼迫队伍沟通站位。

### 倒地与复活

- HP 归零 → **倒地**（不是直接出局），20 秒后自动复活（半血）。
- 队友可消耗**复活令牌**立即复活倒地者：产生一次范围爆炸，对周围敌人造成 100 伤害。
- 复活令牌全队共享，初始 3 个，击败 Boss 补充。
- 死亡变成资源而非惩罚：用得好，故意倒地炸怪是一种战术。

### 团队目标

- 每 3 分钟出现随机团队目标（如"全员在圈内坚守 60 秒"、"集齐 200 个宝石"）。
- 完成 → **全队**获得额外升级或宝箱。
- 目的是给四个人一个共同的注意力焦点，避免各打各的。

## 7. 胜负与结算

- **胜利**：击败奶蛙（第 5 关 Boss）——它会在玩家等级 25 时从场地中央刷新。
- **失败**：角色血量归零。
- 结算数据：存活时长、击杀数、总伤害、最高单次伤害、成型的主要构筑。

## 8. 关键数值框架

| 项 | 值 | 说明 |
|---|---|---|
| 逻辑帧率 | 60 Hz 固定步长 | 可重放 / 帧一致的前提 |
| 玩家移速 | 195 | — |
| 敌人速度 | 70–140 | 必须明显低于 195，否则甩不掉；也不能低于 70，否则追不上 |

| 受击无敌帧 | 0.35 秒 | 防同一帧被多只怪秒杀 |
